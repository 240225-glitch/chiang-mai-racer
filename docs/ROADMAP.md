- [x] 支持三角化、Y-up、单位缩放、材质分组
- [x] 编写运行时加载器（`bkcore/threejs/StaticModelLoader.js`），输出旧版 `THREE.Geometry`
- [x] 接入 Grab3D Race Car 与 Kenney `race-future` 作为测试车
- [ ] 适配 `ShipControls.js` 的尺寸、碰撞半径、相机偏移
- [x] 保留原飞船作为 fallback（主游戏尚未替换）
- [x] 写一份资产导入说明（`tools/README.md`、`assets/README.md`）

**验收**：

- [x] 两辆车在 `tools/model-preview.html` 中正确加载、着色、缩放。
- [x] 贴图、法线、顶点色正确显示。
- [x] 原始 `.obj` / `.mtl` / 下载包不进入仓库，只保留转换产物。
- [ ] 新车辆在 Cityscape 占位赛道可正常驾驶、碰撞、氮气。

## M2 · 古城环线 blockout

目标：用占位几何做出可跑的 6.54 km 环线。

- [ ] 从 OSM 提取环线道路中心线与护城河边界
- [ ] 生成闭合赛道 spline（起点：Tha Phae Gate，顺时针）
- [ ] 生成路面、护城河水面、内外侧路缘
- [ ] 生成四座城门与城墙占位体
- [ ] 设置碰撞走廊（内侧 / 外侧）
- [ ] 设置起点线、4 个分段检查点、圈数触发
- [ ] 接入现有 `Gameplay.js` 圈数系统
- [ ] 双人并排发车点

**验收**：

- 单圈长度 6.5 km ± 3%。
- 车辆无法穿出赛道边界。
- 1 / 3 / 5 圈计数正确。
- 双人分屏各自检查点独立。
- 中画质 60 fps（目标硬件：集成显卡笔记本）。

**风险**：真实道路宽度不足，需在不破坏比例的前提下把可行驶宽度加到 12–14 m。

## M3 · 建筑、地标与街景

目标：让环线看起来像清迈，而不是一条空旷跑道。

- [ ] OSM2World 导出古城建筑（bbox `18.776,98.974,18.800,99.001`）
- [ ] Blender 清理：去重叠、减面、按区块合并
- [ ] 只保留临街 60–80 m 的建筑细节，内部街区用低模块
- [ ] 接入 Wat Chedi Luang（2,151 tris）
- [ ] 程序化生成城门、城墙、护城河栏杆
- [ ] 加入 Tuk-Tuk、Songthaew、树木、招牌、电线杆等道具
- [ ] 远景：Doi Suthep 山体剪影 + 天空盒
- [ ] 烘焙 AO / 简单光照到顶点色或贴图

**验收**：

- 全场景 draw call < 300。
- 可见三角形 < 500k。
- 贴图显存 < 128 MB。
- 古城四个象限均可辨认，至少 3 个地标可识别。

**风险**：10,694 栋建筑直接导入会拖垮旧引擎；Sketchfab 地标面数差异极大（2k → 1.2M），必须逐個减面。

## 关键风险清单

| 风险 | 影响 | 缓解 |
| --- | --- | --- |
| 旧引擎无 glTF / InstancedMesh | 资产无法直接使用、draw call 爆炸 | 离线转换 + 区块合并 + LOD |
| 真实道路过窄 | 高速难会车、双人并排困难 | 可行驶宽度加到 12–14 m，视觉保留原比例 |
| 建筑数量 10,694 | 帧率崩溃 | 只做临街立面，内部低模，按区块合并 |
| Sketchfab 需登录下载 | 地标资产无法自动获取 | 手工下载或改用程序化 / 简化模型 |
| CC BY-NC 底图 | 商用受限 | 默认不用 Sentinel-2，改用程序化地面 |
| 品牌商标 | 法律风险 | 只用原创 / 无品牌车型 |

## 完成定义（Definition of Done）

一个里程碑只有在以下条件都满足时才算完成：

1. 功能可运行，且通过手写验收清单。
2. 文档同步更新（README / ROADMAP / ASSETS / CREDITS）。
3. 新增第三方资产已登记许可与署名。
4. 没有把临时文件、下载包、密钥提交进仓库。
