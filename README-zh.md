# 玩法说明（中文）

本文档是 [README.md](README.md) 的详细补充，记录当前可玩版本的操作、玩法与开发状态。

> 默认入口仍保留 Cityscape；访问 ?track=moat 可进入清迈古城 OSM 外圈赛道。当前包含 6.49 km 道路、19 块护城河水体、4 座城门示意、815 栋临街建筑、按 OSM 真实占地轮廓生成的 Wat Chedi Luang 低模地标，以及暖色示意地面、低模远山、231 棵原创低模树和 109 盏原创 Lanna 风格路灯。所有地理数据按 ODbL 署名；建筑高度、地标三维外观、地面和街景道具位置是游戏示意，不是实测或扫描，树木/路灯位置也不对应 OSM 或真实现场设施。Chrome headless WebGL 已通过，真实 GPU、现场道路和人工完整驾驶仍待验收。

## 启动

- 本地地址：<http://127.0.0.1:8080/>
- 双击项目根目录的 `start-game.bat`，或手动运行：

```powershell
python -m http.server 8080 --bind 127.0.0.1
```

## 操作方式

### 单人模式

| 按键 | 作用 |
| --- | --- |
| `↑` | 加速 |
| `↓` | 刹车 / 后退 |
| `←` `→` | 左右转向 |
| `A` / `Q` | 左侧空气刹车 |
| `D` / `E` | 右侧空气刹车 |
| `空格` / `Shift` | 释放氮气 |
| `P` / `Esc` | 暂停 / 继续 |
| `R` | 暂停或结算时重新开始 |

### 双人模式（左右分屏）

| 玩家 1 | 玩家 2 | 作用 |
| --- | --- | --- |
| `W` / `S` | `↑` / `↓` | 加速 / 刹车 |
| `A` / `D` | `←` / `→` | 左右转向 |
| `Q` / `E` | — | 空气刹车 |
| `左 Shift` | `空格` | 释放氮气 |

- 氮气初始为半管，释放一次消耗半管；比赛中会缓慢回充。
- 驶过红色加速带会立即获得推进，并补充 25% 氮气。
- 也可以直接点击底部的氮气面板释放氮气（方便触摸设备）。
- 双人模式下，任意玩家先完成选定圈数即获胜；一方赛车损毁则另一方获胜。
- 双人模式的成绩不会写入最佳成绩记录。

## 玩法与设置

- **模式**：主菜单可选「单人」或「双人」。双人模式使用左右分屏，两位玩家共用同一块键盘：P1 使用 `WASD` + `左 Shift`，P2 使用方向键 + `空格`。
- **圈数**：主菜单可选 1 / 3 / 5 圈，两种模式通用。
- **难度**：休闲 / 竞技。竞技模式拥有更高的极速和更灵敏的操控。两档难度都调快了转向响应，操控比原版更容易。
- **最佳成绩**：按「赛道 + 难度 + 圈数」分别保存在浏览器 `localStorage` 中，主菜单和结算页都会显示；仅单人模式记录。
- **暂停**：按 `P` 或 `Esc` 暂停，计时会冻结；继续后不会把暂停时间算进成绩。
- **结算页**：单人显示总用时、最佳单圈、每圈成绩、难度 / 圈数和历史最佳；双人显示两位玩家的圈速、进度与胜负。
- **赛后回放**：单人正常完赛后点击「观看回放」，可暂停/播放、拖动进度条、查看时间并返回成绩页；拖动会自动暂停，回放时可用空格播放/暂停、Esc 返回成绩页。主菜单也可观看当前赛道上次有效的单人完赛回放（无需再比赛一次），退出返回主菜单；损坏或不存在的回放不会显示入口。仅保存最近一次成功完赛的本地回放，不是视频文件；双人/损毁赛局不生成回放。
- **画质**：主菜单可切换低 / 中 / 高 / 极高。配置较低时切到「中」或「低」会更流畅；双人模式会自动关闭阴影和全屏后期效果。
- 进入比赛前会显示键位说明，点击画面继续。

## 清迈古城赛道（M2 可玩原型）

默认入口仍使用 Cityscape，保留原版作为兼容和回归测试赛道。通过 ?track=moat 进入清迈古城环线：

- **道路**：来自同一 OSM 官方 API 快照的 90 个 way，650 个路线点，约 6,492.2 m；游戏路宽统一扩展为 14 m，不代表真实道路宽度。
- **护城河**：19 块 OSM water=moat 多边形，不再用规则矩形水带代替。
- **城门**：Tha Phae、Chiang Mai、Suan Dok、Chang Phueak 四个 OSM historic=city_gate 节点；门楼和短墙是程序化示意。
- **临街建筑**：815 栋 OSM 建筑轮廓按路段分块合并为 38 个立面和屋顶网格；暖色顶点色立面带勒脚、木檐、窗框和红瓦攒尖/四坡/截顶四坡屋顶，776 栋高度是游戏估算，39 栋按 OSM 楼层标签推算。
- **Wat Chedi Luang**：新增从同一 OSM 快照提取的寺院范围、古塔、Pra Wihan Luang 和城柱庙建筑轮廓；生成 4 张程序化低模网格，约 230 个三角面。它不是 Sketchfab 扫描模型，也不是历史建筑精确复原。
- **地面与街景**：`TERRAIN_Y=-0.25` 的 16 km 变形地面网格（中心密、边缘疏）和两圈低模远山；231 棵原创低模阔叶树每约 100m 成组布置，109 盏原创 Lanna 风格路灯保持约 60m 节奏。道具避让建筑、水体、城门和警告牌；位置和造型均为游戏美术，不对应真实树木、灯具或历史形制。moat 模式另使用柔和径向暗角与暖色补光/雾，Cityscape 保持原样。当前赛道资产合计 20 materials / 76 meshes / 141,434 triangles。
- **碰撞**：车辆越出路肩时投影回道路并减速，不再立即跌落；Nitro、加速带、单人/双人检查点均沿用现有物理和 Gameplay 系统。

当前路面、路宽、门楼形制、建筑高度与寺庙三维外观仍有示意成分。真实 GPU 性能、实地道路/单行方向、人工驾驶完整绕圈仍未验收。数据来源、快照 SHA 和 ODbL 署名见 [docs/OSM-PROVENANCE.md](docs/OSM-PROVENANCE.md)。

## 赛车模型与兼容性

- Cityscape 默认主车为 Grab3D CC0 赛车；双人模式第二辆为 Kenney race-future。
- 地址加 ?car=kenney 时主车换为 Kenney；地址加 ?ship=1 时回退原版飞船。
- 车辆模型沿用现有 ShipControls.js 物理根节点、碰撞、氮气与圈数系统；资源加载失败会保留原飞船。
- node tests/regressions.js 验证核心驾驶逻辑、模型加载和失败回退。Chrome headless WebGL 冒烟已通过，但不能代替真实 GPU 和目标设备试玩。

## 自动化验证现状

当前仓库内的离线回归与内置浏览器手动检查结果：

- Python：**69/69** 项测试通过，覆盖 OSM 拓扑、建筑/地标数据来源、地面/远山/街景几何、材质、落地与生成器可复现性。
- Node：`node tests/regressions.js` **4 组**通过，覆盖计圈/回放、车辆加载、r50 几何/顶点色校验与道路资源回退。
- 内置浏览器：高画质 `?track=moat&quality=3` 与低画质 `?quality=0` 均可加载 76 个道路子网格、地面、远山、树木和路灯；高画质无六边形暗角，低画质无 Bloom，console 无 error。
- 本机缺少 Selenium，未在本轮重跑完整 `tests/browser_smoke.py`；真实 GPU 帧率、手动 1/3/5 圈和实地路线核验尚未完成。
- 测试专用路线跟随器此前的完整 OSM 圈速仍只用于物理回归，不能证明人工驾驶手感；树木/路灯位置也不是 OSM 实测数据。

### M3 临街建筑、Wat Chedi Luang 与街景

- 815 栋 OSM 临街建筑轮廓按约 350m 路段分块合并为 38 个立面/屋顶网格，避免整圈巨型包围盒拖慢旧 r50 裁剪；776 栋高度是游戏示意估算。立面加入暖色顶点色、勒脚、木檐、窗框，屋顶改为红瓦攒尖/四坡/截顶四坡低模，不增加材质槽。
- Wat Chedi Luang 使用 OSM way 243018795（寺院范围）、93413945（古塔）、93413944（Pra Wihan Luang）和 441418807（城柱庙）作为真实平面定位。
- 生成器新增 4 张程序化地标网格：古塔、塔基支座、主殿/城柱庙墙体、屋顶；合计约 230 个三角面，保持低 draw call。
- 新增 `TERRAIN_Y=-0.25` 的 16 km 变形地面网格、两圈低模远山、231 棵成组原创阔叶树和 109 盏原创 Lanna 风格路灯。建筑、城门、地标、警告牌和道具基座统一落地；树木和路灯避让建筑、水体、城门和警告牌。地面和远山为游戏示意，不是实测地形。
- 当前 `road.json` 为 20 materials / 76 meshes / 141,434 triangles；立面、屋顶、地面、远山和树冠通过顶点色着色，重复运行生成器输出字节一致，`route.json` 和 `route-data.js` 未变。
- OSM 只提供平面轮廓和标签；古塔 38.4m 的视觉高度、屋顶形制、所有立面、树形和灯具造型都是原创游戏示意，不是实测或历史复原。树木/路灯位置不对应 OSM 数据或真实市政设施。
- 新增 tools/osm_wat_chedi_luang.py，要求输入 XML 与道路 route.json 的 SHA-256 完全一致，防止混用不同 OSM 快照。

复现命令：

~~~bash
python3 tools/osm_wat_chedi_luang.py --osm-xml /path/to/chiang-mai-racer-osm.xml --out assets/tracks/chiangmai-moat/source-wat-chedi-luang-osm.geojson --snapshot-date 2026-10-31
python3 tools/build_moat_blockout.py
python3 -m unittest discover -s tests -p 'test_*.py' -v
python3 tests/browser_smoke.py
~~~
