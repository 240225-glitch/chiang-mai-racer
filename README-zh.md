# 玩法说明（中文）

本文档是 [README.md](README.md) 的详细补充，记录当前可玩版本的操作、玩法与开发状态。

> 当前版本仍使用 Cityscape 占位赛道；清迈古城护城河环线正在制作中。玩法系统（单人/双人、氮气、圈数、暂停、结算）已经可玩。

## 启动

- 本地地址：<http://127.0.0.1:8080/>
- 双击项目根目录的 `start-game.bat`，或手动运行：

```powershell
python -m http.server 8080 --bind 127.0.0.1
```

## 操作方式

### 单人模式

| 按键 | 作用 |
| --- | --- |
| `↑` | 加速 |
| `↓` | 刹车 / 后退 |
| `←` `→` | 左右转向 |
| `A` / `Q` | 左侧空气刹车 |
| `D` / `E` | 右侧空气刹车 |
| `空格` / `Shift` | 释放氮气 |
| `P` / `Esc` | 暂停 / 继续 |
| `R` | 暂停或结算时重新开始 |

### 双人模式（左右分屏）

| 玩家 1 | 玩家 2 | 作用 |
| --- | --- | --- |
| `W` / `S` | `↑` / `↓` | 加速 / 刹车 |
| `A` / `D` | `←` / `→` | 左右转向 |
| `Q` / `E` | — | 空气刹车 |
| `左 Shift` | `空格` | 释放氮气 |

- 氮气初始为半管，释放一次消耗半管；比赛中会缓慢回充。
- 驶过红色加速带会立即获得推进，并补充 25% 氮气。
- 也可以直接点击底部的氮气面板释放氮气（方便触摸设备）。
- 双人模式下，任意玩家先完成选定圈数即获胜；一方赛车损毁则另一方获胜。
- 双人模式的成绩不会写入最佳成绩记录。

## 玩法与设置

- **模式**：主菜单可选「单人」或「双人」。双人模式使用左右分屏，两位玩家共用同一块键盘：P1 使用 `WASD` + `左 Shift`，P2 使用方向键 + `空格`。
- **圈数**：主菜单可选 1 / 3 / 5 圈，两种模式通用。
- **难度**：休闲 / 竞技。竞技模式拥有更高的极速和更灵敏的操控。两档难度都调快了转向响应，操控比原版更容易。
- **最佳成绩**：按「赛道 + 难度 + 圈数」分别保存在浏览器 `localStorage` 中，主菜单和结算页都会显示；仅单人模式记录。
- **暂停**：按 `P` 或 `Esc` 暂停，计时会冻结；继续后不会把暂停时间算进成绩。
- **结算页**：单人显示总用时、最佳单圈、每圈成绩、难度 / 圈数和历史最佳；双人显示两位玩家的圈速、进度与胜负。
- **画质**：主菜单可切换低 / 中 / 高 / 极高。配置较低时切到「中」或「低」会更流畅；双人模式会自动关闭阴影和全屏后期效果。
- 进入比赛前会显示键位说明，点击画面继续。

## 当前赛道（占位）

当前版本仍基于 Cityscape 扩展：

- 赛道在 X / Z 方向整体放大 1.5 倍，保留原有高度与碰撞数据。
- 移除了城市高楼，只保留赛道、起点门、加速带和检查点。
- 检查点改为发光的立式光环，穿过光环即可推进圈数。
- 双人模式中两艘飞船并排发车，各自拥有独立相机、HUD 和氮气面板。

这些内容会在 M2 / M3 阶段替换为清迈古城环线。新赛道设计见 [docs/MAP-DESIGN.md](docs/MAP-DESIGN.md)。

## 已实现的功能

- 单人计时赛、同屏双人分屏对战
- 双 HUD、双氮气面板、双相机
- 氮气释放与回充、加速带补氮气
- 1 / 3 / 5 圈选择、休闲 / 竞技难度
- 暂停 / 继续 / 重新开始
- 本地最佳成绩（按赛道 + 难度 + 圈数）
- 中文结算页、每圈成绩、胜负判定
- 完全离线运行，无统计与外链依赖
